Entry for the [Worst Superpower](https://make.fun/bounty/u-suroto-worst-superpower-461dcdbe) bounty on [make.fun](https://make.fun).

## The entry

> I can conjure a perfectly ripe banana out of thin air, but only while I'm already holding one.

A superpower of pure redundancy: conjuring a banana you already hold achieves exactly nothing. The power is genuinely useless, not a curse and not secretly helpful — just pointless, in one breath.

## How it works

`main.py` (Python standard library only) writes the one-liner to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), with no trailing newline.

Run it:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```
